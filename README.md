# Portfólio de Augusto Novaes

Site pessoal para apresentar serviços de criação de landing pages e sites institucionais, explicar o processo de trabalho e facilitar o contato.

## Problema

Quem procura um profissional para criar um site precisa entender rapidamente o que ele oferece, como trabalha e como iniciar uma conversa. Este portfólio organiza essas informações em uma única experiência responsiva.

## Funcionalidades

- Apresentação de serviços e público atendido.
- Processo de trabalho dividido em cinco etapas.
- Case visual responsivo para desktop e celular.
- Seção sobre estudos em automação, agentes de IA e sistemas web.
- Perguntas frequentes e chamadas para contato.
- Navegação responsiva, animações e suporte a `prefers-reduced-motion`.
- HTML semântico, foco visível e link para pular ao conteúdo.

## Tecnologias

- HTML5 semântico.
- CSS com variáveis, layouts responsivos e animações.
- JavaScript puro para navegação e interações.
- Google Fonts e imagens SVG locais.

## Como executar

Não há processo de build. Clone o repositório e abra `index.html` no navegador:

```bash
git clone https://github.com/Augustodevv/site-augustodevv.git
cd site-augustodevv
```

Também é possível usar uma extensão de servidor local, como Live Server.
